# Faisal Stock Radar — clean starter

نسخة تأسيسية عربية تستخدم Flask وMassive API.

## ميزات النسخة
- مفتاح API من صفحة إعدادات المسؤول أو من `MASSIVE_API_KEY` في Render.
- المفتاح المحفوظ من الموقع له الأولوية ويُخزن مشفرًا.
- فحص محدود للأسهم، بحث يدوي، دعم/مقاومة حسابية، قائمة مراقبة وقائمة جاهزة وسجل تقييمات.
- الحالات `PASS / FAIL / UNKNOWN`؛ لا يتم تخمين البيانات المفقودة.

## قيود معلنة
- الفحص محدود بعدد الرموز، ولا يضمن مسح السوق كاملًا.
- Float يظل UNKNOWN لأن الكود لا يستنتجه من shares outstanding.
- الأخبار والتجزئة العكسية والتخفيف وShort Available تحتاج موصلات بيانات فعلية منفصلة.
- يلزم اختبار الكود على اشتراك Massive الفعلي؛ توفر المسارات والحقول يعتمد على الخطة.
- `DATABASE_PATH` مضبوط افتراضيًا على ملف محلي. لتخزين دائم على Render، استخدم قرصًا دائمًا مدعومًا في خطتك واضبط المسار عليه.

## النشر
ارفع الملفات إلى GitHub، ثم أنشئ Web Service في Render. اضبط:
- `MASSIVE_API_KEY`
- `RADAR_ADMIN_PASSWORD`
- `FLASK_SECRET_KEY`
- `RADAR_ENCRYPTION_KEY`

حافظ على ثبات مفاتيح التشفير بعد أول تشغيل، ولا ترفع أي أسرار إلى GitHub.
